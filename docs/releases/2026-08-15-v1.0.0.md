# DVSenseRealtime v1.0.0

发布日期：2026年8月15日

## 版本定位

这是当前稳定的 DVS 单相机采集与官方风格 MATLAB 混合 GUI 基线版本。
该版本用于后续识别算法开发的回退基线，不把尚未实际执行的 GPU 识别标记为已完成。

## 已冻结能力

- 通过隔离的 C ABI bridge 和 helper 进程管理 DVSLume 相机。
- 启动前枚举相机、选择序列号，再建立连接。
- 使用官方事件显示灰度、白色、黑色配色。
- live、DVS 参数、轮廓与中心线分析使用独立窗口。
- 参数页使用事件驱动更新，不再周期性整页重绘。
- 参数展开/收缩保持状态并使用高度过渡。
- 数字参数支持范围限制、加减按钮、精确输入和防抖提交。
- 停止/开始运行命令形成完整闭环。
- 当前测试集：73 项通过。

## 已知边界

- 当前 GPU 后端仍可能回退到 CPU，界面必须显示实际执行后端。
- 轮廓和中心线结果接口已经存在，但下一版本才开始针对真实 DVSLume 事件流校准识别质量。
- 识别路径仍有临时数组分配，需要在下一版本中结合性能数据优化。

## 基线验证

- MATLAB：R2024b
- 相机：DVSLume
- 当前测试序列号：`ffffffffffffffaf`
- 启动日志：`output/matlab-live-startup.log`
